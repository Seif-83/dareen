# Darine – Perfume Website

## 📁 Project Structure

```
darine/
├── index.php              ← Home page
├── shop.php               ← Shop page
├── cart.php               ← Cart page
├── checkout.php           ← Checkout page
├── quiz.php               ← Quiz page
├── blog.php               ← Blog page
├── contact.php            ← Contact page
├── includes/
│   └── process_order.php  ← Backend: validates & saves orders
├── css/
│   └── home.css           ← Main styles
├── js/
│   └── cart_global.js     ← Global cart logic
└── assets/                ← Images and media
```

## 🚀 How to Run

### Local (PHP built-in server)
```bash
php -S localhost:8000
# Then open: http://localhost:8000/
```

### Hosting
Upload all files to a PHP-enabled hosting provider (e.g., InfinityFree, Hostinger, etc.).

## 🛒 Features
- **Responsive Design**: Modern, elegant UI tailored for luxury perfumes.
- **Dynamic Cart**: Add products, view cart drawer, and manage items.
- **Quiz**: Interactive quiz to find the perfect scent.
- **WhatsApp Integration**: Complete orders by sending details directly to WhatsApp.

## 🎨 Design
Fonts: **Cormorant Garamond** and **Jost** via Google Fonts.
Colors: Elegant cream, purple, and muted earth tones.
